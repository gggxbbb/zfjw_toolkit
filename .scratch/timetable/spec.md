# 离线课表与快照差异

设计已确认并完成实现，等待用户验收。研究证据见 [research.md](research.md)。

## 目标与范围

新增独立课表导航入口。用户通过已有 WebView 登录教务平台，采集当前选择学期的完整课表，离线按周查看。支持多学期切换、手动重新采集、课次详情、历史快照及同一学期任意两个快照的比较。

第一版不含课程手工增改、提醒、系统日历导出或历史版本恢复。

## 课次与解析

- 底层数据粒度是每次上课安排，连堂课算一次。第 2–8 周每周一第 1–2 节展开为 7 个课次，每个保留教学周、星期、起止节次、课程名称、教学类型、教师、地点及来源信息。
- 分开解析课程名称、教学类型符号和平台 `【调】` 标记，保留原始标题。符号对应：★讲课、○实验、●实践、◆讨论、※见习、△线上自学。未知符号保留原文。
- 所有页面课次都视为需要上课，不按待筛选／已选上过滤或区别展示。此类状态、颜色、字体变化不参与 diff 或触发快照。
- 周次或节次解析不完整时，阻止整次保存并展示问题原文和原因，保留当前课表。
- 页面明确表示无课时允许空课表；加载中、未识别结构或解析失败不得当作无课。

## 学期设置和展示

- 首次设置第 1 周的周一日期及学期总周数；总周数初始值来自最晚教学周，允许修改。学期设置独立于快照，支持后续校准。
- 默认打开本周，支持切换周、回到本周，突出当天；手机同样采用周一至周日七列、节次为纵轴的布局。
- 上午第 1–5 节：08:00–08:40、08:50–09:30、09:40–10:20、10:30–11:10、11:20–12:00。
- 下午第 6–10 节：14:00–14:40、14:50–15:30、15:40–16:20、16:30–17:10、17:20–18:00。
- 晚间从第 11 节 19:00 开始，每节 40 分钟、课间 10 分钟。默认显示至第 13 节 20:40–21:20；某周存在更晚课次时只对该周延长显示，不丢弃数据。
- 卡片展示干净课程名、教学类型文字标签及调课徽标；详情保留原始标题。
- 同日节次重叠的课次并排显示并标记时间冲突，每个课次均可独立打开详情。

## 更新、快照和 diff

- 重新采集发现变化时先展示与当前课表的 diff，用户点击“使用新课表”才保存新快照并更新当前课表；失败或未确认时保留原数据。
- 内容无变化不新增快照，只更新最后检查时间并提示无变化。
- 历史快照仅供查看与比较，不提供恢复或设为当前版本的入口。
- diff 按课次比较，展示新增、取消及字段变化。平台调课标记的增减也算变化，明确标注并在确认后保存快照；不凭平台标记推断调整前安排。
- 同名同教学类型的课次按时间排序，以顺次编号作为配对线索而非唯一身份。优先匹配时间和内容未变化的课次，再结合前后顺序辅助匹配剩余项；无法可靠对应时显示移除与新增。
- 若已存在课表而新结果明确为空，展示全部移除并等待确认后保存。

## 实现方向与验证

复用现有 WebCapturePage 的登录、页面匹配、脚本注入和确认流程；新增独立课表解析、课次模型与页面。持久化沿用 ADR-0003 的 drift 方向，新增课表数据结构并验证旧数据库升级。

实现中需验证实际 DOM 的星期定位、跨行单元格、异步学期切换和加载完成信号；不得仅以 DOM 块计数或空数组判定完整采集。表格和列表视图只能选一份数据，避免重复。

针对周次展开、连堂课、未知符号、调课标记、部分失败、明确空课表、无变化去重及取消／新增／跨次调课的配对边界进行验证；同时覆盖确认前不写入、历史不可恢复、数据库升级和窄屏七列布局。

教学周之外的默认定位、学期设置合法性及无法确认的解析结构等实现边界，实施前结合代码与页面证据确定；如涉及新的产品取舍，再向用户提出单项问题。

## 实现证据

- 真实教务课表页面验证采集到 155 个安排块，星期一至星期日均能定位；脱敏页面数据作为解析回归样本。
- 覆盖课次展开、连堂、教学类型、平台调课标记、严格失败、明确空课表、快照去重、任意版本比较、数据库 v1 升级及 390 像素宽七列布局。
- Windows Release 与 Android Debug APK 构建通过；Flutter 全套测试、静态分析和课表采集 JavaScript 测试通过。
- 用户实测发现 WebView 文本代理缺少 `textContent` 时采集失败；已用同一 `TypeError` 建立回归并兼容 `textContent`、`innerText` 与 option `text`。
