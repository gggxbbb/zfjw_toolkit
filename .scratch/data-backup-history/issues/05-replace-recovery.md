# 05 — 替换式恢复与中断恢复

**What to build:** 在导入预览后为用户提供替换本机数据的恢复模式，通过额外确认、恢复日志和启动时恢复机制，保证失败或进程中断后不会留下无法判断的混合状态。

**Blocked by:** 04 — 备份导入预览与合并恢复.

**Status:** ready-for-agent

- [ ] 预览页提供与“合并”明确区分的“替换本机数据”动作。
- [ ] 替换操作在执行前进行第二次破坏性确认，并说明将被替换的数据范围。
- [ ] 替换成功后，本机档案、快照、教学计划、overrides、GPA 目标和规则包与备份一致，且相关页面统一刷新。
- [ ] 任一步骤失败时恢复导入前的数据库和键值状态，并只报告失败，不报告部分成功。
- [ ] 恢复操作具有可持久化的进度/恢复记录；应用启动时能够识别并完成回滚或安全收尾。
- [ ] 恢复记录在成功提交或成功回滚后清除，重复启动保持幂等。
- [ ] 自动化测试覆盖确认取消、正常替换、各阶段失败、模拟中断和下次启动恢复。
