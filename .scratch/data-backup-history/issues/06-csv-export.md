# 06 — 当前与历史成绩 CSV 导出

**What to build:** 让用户从数据中心把当前有效成绩或指定历史快照的原始成绩保存为适合 Windows 表格软件打开的 CSV，同时明确该文件不能用于完整恢复。

**Blocked by:** 01 — 设置入口与只读历史快照.

**Status:** ready-for-human

- [x] CSV 导出提供“当前有效成绩”和“历史快照原始成绩”两个清晰模式。
- [x] 历史模式允许从已有快照中选择一项，且不会改变当前快照。
- [x] 当前模式应用现有成绩 overrides；历史模式导出不可变原始记录。
- [x] CSV 使用稳定中文列头、UTF-8 BOM 和标准字段转义，兼容中文、逗号、引号、换行及空字段。
- [x] 保存前明确提示 CSV 只用于表格分析，不能恢复完整应用数据。
- [x] 用户取消不生成文件；保存成功和失败均给出准确反馈。
- [x] 字节级测试覆盖 BOM、列顺序、转义和两种模式；组件测试覆盖选择、取消与成功导出。
