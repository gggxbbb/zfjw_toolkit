# 03 — 完整 JSON 备份导出

**What to build:** 让用户从设置的数据中心选择保存位置并导出一个可审计、可恢复的完整 JSON 备份，覆盖应用管理的全部学业数据和分析设置，同时明确保护个人数据且不包含登录状态。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 定义并实现带整数格式版本、导出时间和应用版本的稳定备份文档。
- [ ] 备份包含档案、全部成绩快照、稳定 ID、原始来源/时间、教学计划、成绩与计划 overrides、GPA 目标和规则包。
- [ ] 备份明确不包含密码、Cookie、WebView 数据、缓存或临时界面状态。
- [ ] 设置数据中心的导出动作先展示个人数据提示，再使用平台文件界面选择目标并写入 UTF-8 JSON。
- [ ] 用户取消保存不产生文件、不显示错误成功态；写入失败显示可操作错误。
- [ ] 导出逻辑通过可替换的文档网关运行，移动端与 Windows 使用同一业务契约。
- [ ] 往返测试证明所有字段、稳定 ID 和时间戳无损；组件测试覆盖确认、取消和成功结果。
