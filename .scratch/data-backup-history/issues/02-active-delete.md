# 02 — 当前快照切换与历史快照删除

**What to build:** 让用户可以在历史详情中显式把某个快照设为当前，或在确认后删除快照；成绩、目标分析和数据管理随后一致使用新的当前数据，删除当前项时安全回退。

**Blocked by:** 01 — 设置入口与只读历史快照.

**Status:** ready-for-agent

- [ ] 档案可持久化一个可空的当前快照选择；既有数据库迁移后默认行为仍是使用最新快照。
- [ ] 历史详情提供“设为当前”动作，并在确认信息中说明现有 overrides 会应用到新当前快照。
- [ ] 仅浏览历史不会切换；成功切换后列表标记、成绩统计、目标分析和数据管理同步刷新。
- [ ] 删除任何快照前均要求确认，并在界面上明确时间和来源。
- [ ] 删除当前快照后自动选择最新的剩余快照；删除最后一个快照后清空选择并进入正常空态/手动数据状态。
- [ ] 删除失败或切换失败时保留原当前快照并显示可操作错误。
- [ ] 仓储测试覆盖选择、默认最新、删除回退和空列表；组件测试覆盖确认与跨页面可见结果。
