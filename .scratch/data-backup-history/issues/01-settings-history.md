# 01 — 设置入口与只读历史快照

**What to build:** 在设置页提供统一的“数据与备份”入口，并交付可实际浏览的历史快照列表和原始详情。用户可以从数据中心继续进入现有数据管理功能，在历史列表中识别当前项，但浏览行为不会改变当前统计数据。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 设置页新增“数据与备份”入口，并打开独立数据中心。
- [ ] 数据中心包含“管理与编辑数据”“历史快照”“导出完整备份”“导入完整备份”“导出 CSV”的稳定信息架构；尚未实现的后续动作有明确的不可用状态而不是空白跳转。
- [ ] 历史快照按采集时间倒序展示，并显示来源、课程数和基于原始记录的 GPA 摘要。
- [ ] 当前快照在列表中具有可访问的文字/语义标记。
- [ ] 历史详情展示该快照的原始课程记录，不应用当前成绩 overrides。
- [ ] 浏览或返回历史详情不会改变成绩页与目标分析页当前数据。
- [ ] 数据中心和历史页面在窄屏使用单列，在宽屏遵循现有自适应内容布局。
- [ ] 组件测试从设置入口走到历史详情，并证明显示的是原始记录。
