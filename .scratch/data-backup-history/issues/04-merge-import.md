# 04 — 备份导入预览与合并恢复

**What to build:** 让用户选择完整备份文件，在任何写入前看到内容预览，并把不冲突的数据合并到本机；重复导入保持幂等，冲突或损坏文件不会修改本地状态。

**Blocked by:** 03 — 完整 JSON 备份导出.

**Status:** ready-for-agent

- [ ] 导入只接受支持的完整备份格式，并在写入前完成全文件解析和字段校验。
- [ ] 未知的新格式版本、无效枚举、缺失字段、非法 ID/时间或损坏记录显示具体错误且零写入。
- [ ] 预览显示将新增、跳过和冲突的档案/快照数量，以及教学计划、overrides、目标和规则包是否存在。
- [ ] 合并时，相同稳定 ID 且内容相同的实体被跳过；相同 ID 但内容不同会阻止合并，绝不静默覆盖。
- [ ] 成功合并保留原始快照来源和采集时间，并刷新所有相关数据页面。
- [ ] 用户取消文件选择或预览不修改任何数据。
- [ ] 恢复协调器记录导入前状态并在任一存储步骤失败时补偿回滚，不产生用户可见的半套结果。
- [ ] 测试覆盖有效合并、重复合并、冲突、损坏文件、用户取消及每个写入边界的失败注入。
